# 🎀 Dhruvi's Little Wonderland | Made With Love ❤️

A magical, interactive Children's Day surprise website dedicated to Dhruvi.

---

## 🌸 Features Included

1. **The Magical Entry Experience**: Dreamy pastel-pink sky, floating hearts, kitten holding pink heart, "HEYYYY DHURVIIIII!! 🎀", confetti heart explosion & fanfare sound on unboxing.
2. **Hero Section (Children's Day Celebration)**: "HAPPY CHILDREN'S DAY, MY LITTLE BABYYYY!! 🧸", animated teddy bears, balloons, flowers, "Officially the cutest princess in the universe" badge, interactive "YES, I'M THE PRINCESS 👑" button, and "How much do you love me?" Love-O-Meter!
3. **The Cutest Kitten Paradise 🐱**: 20 curated high-resolution kitten photos in a Pinterest scrapbook grid with categories (Sleepy, White, Orange, Bows, Flowers, Teddy, Blanket, Funny, Box, Camera), washi tapes, modal with affectionate messages, floating hearts, and "SHOW ME MORE CUTENESS 🐾".
4. **Digital Love Letter Collection 💌**: Vintage mailbox with 5 physical opening envelopes sealed with wax hearts:
   - Letter 1: OPEN WHEN YOU MISS ME
   - Letter 2: OPEN WHEN YOU FEEL SAD
   - Letter 3: OPEN WHEN YOU NEED A SMILE
   - Letter 4: OPEN WHEN YOU CAN'T SLEEP
   - Letter 5: OPEN WHEN YOU FORGET HOW SPECIAL YOU ARE
5. **The Mystery Gift Room 🎁**: 6 interactive gift boxes:
   - Gift 1: The Virtual Hug
   - Gift 2: Unlimited Kisses
   - Gift 3: Chocolate Heaven
   - Gift 4: The Compliment Machine (interactive random compliment generator!)
   - Gift 5: The Magic Mirror (Dhruvi. Obviously. No competition.)
   - Gift 6: The Secret Gift (Multiverse promise)
6. **50 Tiny Reasons Why I Adore You**: 50 numbered flip cards with adorable reasons and reveal-all toggle.
7. **The Interactive Love Button 💗**: Giant pulsating pink heart with 30-50 floating hearts explosion on every tap, pop/heart sounds, and affectionate messages.
8. **The Hidden Secret Messages (Easter Egg Hunt)**: 10 hidden clickable secrets scattered across the website, secret journal drawer, and grand **10/10 Trophy Achievement Modal**.
9. **The Mini Love Game 🎮**: "HOW WELL DO YOU KNOW YOUR SECRET ADMIRER?" 5 playful trivia questions with 100/100 celebration & confetti!
10. **The Teddy Bear Hug Station 🧸**: Large animated teddy with "Give me a hug", "Give me a kiss", and "Pat my head".
11. **The Childhood Dream Room 🎠**: Nostalgia room with interactive fairy lights, candy jar, soap bubbles, and toy train.
12. **The Virtual Date Night 🍦🌙**: 4 interactive dates (Ice cream, Stargazing, Movie night, Chocolate date).
13. **The Floating Music Corner 🎵**: Animated vinyl record player with visualizer, dreamy synthesized romantic lofi piano melody, and custom MP3 file upload!
14. **The Final Secret Love Letter 🌙**: Dreamy night sky scene with crescent moon, golden envelope with the full emotional letter, "ONE LAST SURPRISE? 👀" full-screen heart animation, and the Secret Birthday-Style Gift Box!
15. **Secret Night Mode 🌙**: Toggle to transform wonderland into a dreamy starry midnight theme!
16. **Floating Mascot Kitty 🐱**: Walks in bottom corner and shares cute thoughts when clicked.

---

## 🚀 Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Build for production
npm run build
```

---

## 🌐 Deploying to Vercel

```bash
# Option A: Install Vercel CLI and deploy
npx vercel

# Option B: Push this repository to GitHub and connect to Vercel (https://vercel.com)
# Suggested domain: dhruvis-wonderland.vercel.app
```
